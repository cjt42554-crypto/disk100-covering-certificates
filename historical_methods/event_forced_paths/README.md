有限路径校正始终优化固定旋转片的 **全部 199 个中心坐标自由度和 t**，约束当前真实孔 `gk(C)≤t` 与解析 incircle 事件等式。实际孔清单持续更新，没有固定旧 active keys，也没有释放 offset。每个保存节点用独立 `true_cover` 枚举所有 4950 对的单位圆交点、所有中心的边界反向驻点和盘内 Delaunay 顶点，以所有中心的最近距离评分。全初始 DT、圆心穿界、边界最近中心切换事件的数值余量另行复验保存。纯盘外 DT 变化未被误作覆盖逃逸而盲停。

事件前后先在原全孔、零 offset 问题中保留对应对角线侧，随后将侧余量降至零，最终撤去事件条件，完全恢复原问题并独立评分。所有最终恢复候选均有坐标文件及哈希。全过程使用一个 CPU/BLAS 线程；接受节点未超过 `R=0.13`、相对基线最大中心位移 `0.3` 的预算。

限制与失败记录：

- 表中峰值仅是保存的接受节点最大值，**不是整段路径上确界证书**。
- 12 条均保存事件前后 `(+1,-1)` 的精确有理 incircle 符号；该精确性只针对保存的 binary64 坐标。数值共圆节点并非代数精确零点，不能据此宣称精确事件或代数路径认证。
- e0093 在进度 1.0015 的 SLSQP 校正达到迭代上限，事件等式余量未达到接受门槛；此前进度 1.001 已通过。三个失败尝试节点全部保留，未作为有效节点计入采样峰值。
- e0093 和 e0007 的部分强制路径节点，约束 tangent Hessian 最小特征值分别约 `-4.57e-10` 与 `-1.69e-10`，没有严格正曲率结论。有限路径使用 `Hforced=Σλj Hess(gj)+ν Hess(e/e0)`，事件乘子 ν 不限制符号。曲率只诊断 active 等式子空间，不能替代临界锥、区间余项或全局证明。
- 共圆时两个邻孔半径差与事件等式存在微分依赖；保存的 epigraph 秩亏已明确记录，不能将这些行当成相互独立的等式。
- 事件后恢复的最好半径为 `0.11551610349101131`，仍较基线差。没有新 U，也没有复核或提升已有独立下界。
